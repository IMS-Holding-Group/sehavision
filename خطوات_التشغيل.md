# Setup Guide - SehaVision

## Basic Requirements
- Node.js 16+ | Python 3.10.6 | Flutter 3+ | Tesseract OCR

---

## Quick Start

### 1. Server (Node.js)
```cmd
cd backend
npm install
node scripts/init-db.js
npm start
```
→ Running on: `http://localhost:3000`

### 2. AI Service (Python)
```cmd
cd backend\ai_service
pip install -r requirements.txt
python app.py
```
→ Running on: `http://localhost:5000`

### 3. Main App (Flutter)
```cmd
cd frontend
flutter pub get
flutter run
```

### 4. Admin Panel (Flutter)
```cmd
cd admin
flutter pub get
flutter run
```

---

## Verification
- Server: `http://localhost:3000/api/health`
- AI: `http://localhost:5000/health`

---

## Notes
- **Startup Order:** Server → AI → Apps
- **API URL in Flutter:** `10.0.2.2:3000` (for emulator) or `YOUR_IP:3000` (for real device)
- **Create Admin Account:** `node scripts/init-admin.js` (in backend folder)
